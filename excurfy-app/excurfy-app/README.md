# Excurfy

Plataforma de gestão de excursões — Next.js + Supabase.

## Rodar localmente
npm install
npm run dev   # http://localhost:3000

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Na Vercel: Add New → Project → importe o repositório (framework: Next.js).
3. (Opcional) Variáveis: NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY.
